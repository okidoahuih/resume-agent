# 投简历 Agent（iPhone 可用 MVP）

这是一个无需安装依赖的移动端控制台原型。直接用 Safari 打开 `index.html` 即可体验：

- 推荐岗位、匹配度和投递状态
- 模拟扫描岗位与投递队列
- 本机保存个人资料（localStorage）
- 投递规则开关和安全提示

## 在 iPhone 上打开

最简单的方式是把本目录部署到任意静态托管（GitHub Pages、Vercel、Cloudflare Pages 等），然后用 iPhone Safari 打开网址，并选择“添加到主屏幕”。本地双击 HTML 适合电脑预览，iPhone 端建议使用 HTTPS 地址。

## 下一步接入真实自动投递

需要增加一个云端执行器（浏览器自动化或招聘平台官方接口）、账号授权、岗位来源和人工确认回调。建议保留“先确认再投递”，验证码和最终提交不自动绕过。
